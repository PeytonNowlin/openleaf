OpenLeaf demo

A custom element bound to a textarea. Submitting posts HTML in body, exactly as a TinyMCE integration would. Try pasting from Word or Google Docs and watch the raw HTML.

Keyboard and screen reader notes

  • Alt+F10 moves focus into the toolbar; Esc returns to the content.
  • Arrow keys move between toolbar buttons — the whole toolbar is one tab stop.
  • Tab is deliberately not captured, so it always leaves the editor.
  • List indentation is Ctrl/⌘+[ and ].

A restricted toolbar

Integrators choose which controls appear, and in what order, with the toolbar attribute. This one is themed only through custom properties.
